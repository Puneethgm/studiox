Project-X
01 / 04 — Vision

An AI-run marketing agency for fitness studios — that grows into their full operating system.

A single platform that plans, publishes, and sells on a studio's behalf from day one, then expands into bookings, CRM, and predictive operations as the studio scales.

Today, a studio owner juggles five disconnected tools — a scheduling app, an ads manager, a DM inbox, a spreadsheet of leads, and gut instinct for who's about to walk. Project-X collapses that into one system that generates content, runs paid campaigns, catches every lead in one inbox, and scores each one by intent — so the studio spends its time closing, not chasing.

Model
Multi-tenant SaaS — franchise / aggregator across many studio vendors
Wedge
AI-managed marketing agency, live and generating leads within 24 hrs of onboarding
Moat
Unified lead data + sentiment scoring compounds per studio, per channel, over time

04 / 07 — Current State
Live today — L1

Not a slide deck — a working multi-tenant platform.

Super-admin provisions studios in seconds; each studio runs its own branded campaigns, public lead form, and live inbox today.

Multi-tenant core

Super-admin creates studios with name, brand color, logo, first admin login. Studio-scoped auth via JWT, fails closed on any tenant mismatch.

Branded lead capture

Public form at /l/<studio>/<campaign>, themed per studio's brand color. Leads land in Postgres and sync to Google Sheets via a durable outbox.

Pipeline & leads

Kanban pipeline across 5 stages (new → contacted → trial → member → dropped), paginated lead lists, live funnel + status widgets per studio.

WhatsApp inbox

Direct Meta WhatsApp Cloud API integration — per-studio channels, live conversation stream (SSE), idempotent inbound webhook, encrypted tokens at rest.

Identity stitching

Contact identities unified per studio across channels, optionally linked to a lead — the same architecture that will carry IG, Messenger, and X.

Role-aware admin UI

Single Next.js app, sidebar shell that re-themes per tenant via CSS variables — one login URL routes super-admins and studio-admins correctly.

Automation-ready schema

Tables for message templates, automation rules, AI suggestions, and message analysis already exist — next phases add writers, not new migrations.

Production deploy

Dockerized on a single EC2 box behind nginx, atomic migrate-then-deploy, nightly backups — a real environment, not a demo sandbox.

05 / 07 — Security & Governance

Enterprise-grade access control, built in from L1.

Eleven roles, permission-scoped to (resource, action, scope) — not bolted on later as an afterthought.

Platform Super Admin

Full platform control — vendor provisioning, billing, feature flags.

Vendor Owner / Admin

Full control over a tenant and its studios; billing and user management.

Studio Manager

Scoped to specific studios — staff, timetable, bookings, local marketing.

Marketing Manager

Content, campaigns, budgets, and lead inbox for assigned studios.

Sales Agent

Assigned leads only — message, log activity, close sales.

Trainer / Finance

Own schedule & clients — or billing/payouts with zero lead access.

Auditor / Compliance

Read-only across audit logs, consent records, and data exports.

Enforcement

Centralized policy service checks every action; row-level security per tenant; every privileged action is immutably logged.
